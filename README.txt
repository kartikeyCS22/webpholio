Webpholio
=========
index.html        the site (open it directly, or drag the whole folder onto Netlify)
assets/           logos, loaded with <img src="assets/...">

Add or change a project: edit the DEFAULTS list in index.html
(search for "const DEFAULTS"). Put a logo in assets/ and set
thumb:'assets/your-logo.png' on that project.
